# STP Viewer V1.1.00

本次更新重点改善装配 BOM 导出、模型着色和三维观察，并加入零件位置编辑及整装 STEP 另存功能。模型继续在本机离线处理，不上传文件，不改写当前导入的源 STEP。

## Excel BOM 层级显示

- “装配层级”成为默认打开页，采用 `1、1.1、1.1.1` 层级编号、名称缩进和装配行加粗底色。
- 使用 Excel 原生行分组，可通过左侧 `＋／－` 展开和收拢；默认显示根节点及下一层，冻结表头和名称列。
- 保留四张工作表、勾选导出范围、重复实例、数量统计与完整路径。超过 Excel 7 层嵌套分组上限时，节点数据完整保留，并在诊断页说明限制。

## 全局随机着色与单面着色

- 新增“全局随机着色”：覆盖当前文件全部叶级零件，包括隐藏项；相同定义名称的零件保持同色，优先提高邻近异名零件的颜色区分度。
- 新增“选面”模式，可对单个实例的原始几何面独立设置颜色或恢复底色；同源的其他实例不串色。
- 支持颜色撤销、重做和恢复全部原色；随机配色作为一步撤销，重新配色会替换已有手动整件色和面色。
- 整件色与面色可通过“另存 STEP”保存，重新打开后保留。单面颜色优先于整件颜色，网格精度重建后仍保持有效。

## 三维窗口全屏与全屏抓手

- 视口右下角新增四角 L 形全屏按钮，进入时向外扩展、退出时向内收缩，动画约 180 毫秒。
- 全屏继续使用原有三维视图，保留相机、选择、剖切和颜色；退出后恢复原窗口、最大化状态及面板布局。
- 全屏抓手位于退出按钮左侧，与普通窗口共用同一开关。开启后可左键拖动零件，关闭后恢复左键旋转；退出全屏保留抓手开关及临时摆放。
- 支持 Esc 退出；正在拾取时优先取消拾取。切换、打开或关闭文件及需要其他面板的操作会先退出模型全屏。

## 零件位置编辑、整装另存与剖切

- 新增单个零件实例的数值平移、旋转、旋转中心选择、预览、应用、取消、撤销和重做。
- “另存 STEP”保存完整装配、已应用的位置与颜色；各文件标签独立维护编辑历史，并提示未保存改动。
- 自定义剖切支持标准基准面、拾取零件平面、旋转及精确偏移；封盖可跟随零件整体颜色。
- 背景支持渐变、白色、浅灰、深灰和自定义颜色，跨标签同步并在下次启动保留。

## 修复与功能调整

- 修复选面着色后点击模型空白导致程序意外退出的问题。
- 普通空白点击仅取消面选择与高亮，保留颜色；Ctrl／⌘ 点击空白保留多选，不增加颜色撤销步骤。
- 改善全屏切换、面板恢复、抓手状态同步和模式互斥，补充真实鼠标及跨平台回归。
- 移除开发分支中未完善的客户外包络、连接器保留、保护空间及外包络诊断修复模块。普通剖切、移动旋转、整装另存和零件拆分继续提供。

## 下载与启动

- **Mac Apple Silicon**：`STPViewer-1.1.00-macos-arm64.zip`，完整解压后打开 `STPViewer.app`。
- **Windows 单文件**：`STPViewer-1.1.00-windows-x64-portable.exe`，可独立复制；首次启动校验并展开运行库到当前用户缓存。
- **Windows ZIP**：`STPViewer-1.1.00-windows-x64.zip`，完整解压后运行 `STPViewer.exe`，保留全部 DLL、插件及资源。
- 附源码 ZIP、SHA-256 校验文件、使用说明与验证报告。

## 保存范围与验证边界

- 整装 STEP 另存不导出 PMI，也不写入会话中人工补填的材料／密度；剖切、隐藏、透明、爆炸和抓手临时摆放均只影响显示。拆分导出和 Excel 继续遵守各自原有数据范围。
- 当前功能已完成 Apple Silicon Mac 本机及 VMware Windows 11 ARM64 的 x64 仿真回归；后者不等同于原生 Windows x64 硬件验收。具体以各包验证报告为准。
- Mac 使用 ad-hoc 签名，未做 Apple 公证；Windows 未做 Authenticode 签名。
- Excel 原生大纲依赖客户端支持；超深层级保留完整数据，但受原生折叠层数限制。
