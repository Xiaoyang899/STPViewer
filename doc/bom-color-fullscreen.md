# BOM 树、模型着色与三维全屏

本说明对应当前开发版的五项调整：移除客户外包络、Excel 装配树、全局随机着色、单面着色和三维窗口全屏。Mac 与 Windows 测试包按各次交付记录提供。源码功能说明不代表各平台均已验收；实际构建、原生交互、Excel 客户端展开/收拢和便携包验证范围以对应的交付报告为准。

## 客户外包络已移除

移除“客户外包络”相关入口、配置对话框、生成和导出模块。本版不再提供外包络预览或客户外包络 STEP 导出。工程信息中的包围盒尺寸、普通模型查看、剖切、Excel BOM、整装 STEP 另存和拆分导出继续提供。

## Excel 打开即显示装配树

点击 **导出 Excel BOM** 后，工作簿仍包含“零件汇总”“装配层级”“实例位置”“导入诊断”四张工作表，默认打开 **装配层级**。

装配层级按父项在前、子项紧随其后的顺序排列，前四列为 **层级序号、名称、类型、本行数量**。层级序号采用 `1`、`1.1`、`1.1.1` 的形式；名称随深度缩进，装配行加粗并使用浅色底纹。后面保留实例 ID、父实例 ID、真实层级、定义 ID 和实例路径，方便核对来源。表头及前两列冻结，横向滚动仍能看到名称。

默认显示根节点及其直接子节点，更深层节点收起。使用 Excel 左侧大纲的 **+ / −** 展开或收拢子项，也可通过级别按钮调整整体显示深度。这是 Excel 原生分组，不依赖宏。树表不设置自动筛选，以保持父子行连续；需要筛选零件时使用“零件汇总”。手工排序树表可能破坏分组对应关系。

Excel 大纲最多支持 **7 个嵌套分组级别**，本版使用级别 `0–7`，根节点为 `0`。超过深度 7 的节点仍全部保留，但不能继续逐层独立折叠；层级序号、真实层级和实例路径继续记录完整结构，“导入诊断”会说明这一限制。名称缩进最多显示 15 级，避免极深装配将名称推到不可读的位置。

导出范围仍由 BOM 勾选的叶级实例及其必要祖先决定。树中每行对应一个实际实例，**本行数量为 1**，重复子装配或同名零件不会在树中合并。“零件汇总”仍按零件定义统计所选实例数量，同名但不同定义的零件分别计数。原始实例位置、人工属性来源和取消时不改写已有目标文件的规则保持一致。

## 全局随机着色

点击工具栏或 **视图 → 全局随机着色**，对当前文件的全部叶级零件实例重新分配颜色，包含未勾选或临时隐藏的实例；其显隐状态不因此改变。再次点击会重新生成一组配色。

相同名称的零件使用相同颜色。名称取自 BOM 的零件定义名称，比较前执行 Unicode NFC 规范化并去除首尾空白；保留大小写和内部空白差异。没有名称时按定义 ID 分组。该名称规则仅用于配色，不会改变 BOM 定义或数量统计。

配色根据零件在原始装配位置加上已应用的位置编辑后的包围盒，估计相邻关系，优先提高邻近、不同名称零件之间的颜色差异。爆炸和抓手的临时显示位移不参与邻接计算。同名零件即使相邻也保持同色；有限色盘、密集或大型装配的近似邻接计算不能保证任意两件相邻零件都达到固定色差。

**全局随机着色会替换已有手动整件颜色，并清除手动面颜色。** 整次操作可通过 **视图 → 撤销着色** 恢复，也可“重做着色”。“恢复全部原色”清除当前文件的所有颜色编辑，恢复本次导入文件的颜色；该操作同样可以撤销。颜色撤销与临时透明/隐藏的“还原一步”分别管理。

## 给单个面设置颜色

1. 在工具栏将 **选零件** 切换为 **选面**。
2. 点击模型上的原始几何面，选中面显示高亮轮廓。按住 Mac 的 ⌘ 或 Ctrl 可追加或取消多选。
3. 点击 **面颜色…** 选择颜色。修改只作用于选中的实例和面，同一定义的其他实例不跟随改变。
4. 使用 **恢复选中面底色** 清除所选面的手动覆盖，显示该零件当前底色；使用“撤销着色”或“重做着色”回退或恢复操作。切回“选零件”或按 Esc 结束选面。

手动面颜色优先于整件颜色；之后修改整件颜色会保留已设置的手动面色。“恢复选中零件原色”会同时清除该实例的整件及手动面色。颜色编辑按文件标签独立保存于会话。

在选面模式下，普通点击模型空白处只取消面选择，不删除已设置的颜色；按住 Ctrl／⌘ 点击空白保留多选。可以继续重新选面着色。

本轮元素着色支持 **面**，不提供独立的边、点或剖切临时封盖着色。选面与测量拾取、剖切基准面拾取和抓手操作互斥。剖切封盖不是原始几何面；使用“对象颜色”封盖时，它按零件主色显示，不按每个手动面色拆分。

通过 **另存 STEP** 可保存完整装配、已应用的位置编辑、整件颜色及面颜色。为防止颜色串到重复实例，具有不同着色的实例可能在输出 STEP 中使用独立定义，几何仍使用精确曲面和曲线。关闭有未保存位置或颜色编辑的文件时，会提示保存、放弃或取消。

整装另存不导出 PMI，不写入人工补充材料/密度，也不保存爆炸、抓手、透明、隐藏、剖切或封盖这些显示状态。它保存整个装配，包括未勾选和隐藏实例；如文件有 PMI，会在另存前提示。**拆分导出 STEP** 和 Excel 仍使用导入数据及原有范围语义，不包含本次颜色或位置编辑；要保留新颜色应使用“另存 STEP”。

## 三维窗口全屏

三维视口右下角新增由四个 **L 形角** 组成的按钮。正常布局点击后，四角向外扩展约 **180 ms**，随后进入模型全屏；菜单、工具栏、侧栏和底部控制区暂时收起。按钮在全屏时仍位于右下角，再次点击时四角向内收缩约 **180 ms**，退出后恢复进入前的窗口及面板布局。

全屏时，右下角方形按钮左侧同时显示抓手按钮，点击即可开启或关闭。展开手掌为关闭，蓝底抓握手掌为开启；与普通窗口的抓手开关保持同步。开启后左键拖动一个零件，关闭后左键恢复旋转，右键平移与缩放不变。退出全屏会结束正在进行的拖动，但保留抓手开关和临时摆放位置。抓手位移仍只用于显示，不写入整装 STEP。

全屏过程中继续使用原有三维视图，保留相机、选择、剖切、颜色及其他模型状态。Esc 优先取消当前拾取操作，没有拾取操作时退出模型全屏。切换文件、关闭当前文件或打开需要面板的操作时，会先恢复正常布局。鼠标悬停提供进入/退出提示，按钮可通过键盘聚焦和激活。

## 验证边界

本轮新增了 XLSX 内部结构、颜色分组与面色保存、原生界面及全屏相关回归入口。测试结果与测试包身份应以本次交付报告为准，不能从本文推断全部测试已经通过。Excel 的大纲按钮行为还取决于具体客户端；其他表格查看器可能不支持或不完整支持分组。历史 Windows 发布包和 Windows 11 ARM 上运行 x64 程序的记录，不构成本开发版 Windows x64 原生验收。
